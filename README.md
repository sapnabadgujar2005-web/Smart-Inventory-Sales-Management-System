# Smart-Inventory-Sales-Management-System
Smart Inventory &amp; Sales Management System is a Python Based desktop application designed to manage products, inventory and sales efficiently through a user-friendly graphical interface.

## Key Features
-User Login
-Product Management
-Inventory Management
-sales Management
-Product Search
-Add, update and delete Records
-User-Friendly Tkinter UI
-Database based data Storage

#Technologies used

-Python
-Tkinter
-SQLite\MySQL
-SQL

##Project Objective
The main Objective of this project is to develop a simple computerized system that helps manages inventory and sales operations efficiently while reducing manual record keeping.
